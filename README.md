# Atlas AI 20.7 — Executive Experience

This release adds visible executive-dashboard upgrades:

- New executive welcome banner
- Animated KPI values
- Interactive CEO Action Center
- Savings timeline
- Atlas Intelligence feed
- Larger Ask Atlas workspace
- Typing indicator and conversation history
- Working quick prompts, navigation, report modal, and presentation mode

## Deploy

1. Unzip this package.
2. Open the extracted `atlas-20.7` folder.
3. Upload the **contents inside the folder** to the existing GitHub repository.
4. Commit the changes.
5. Vercel will deploy automatically.

Build command: `npm run build`
Output directory: `dist`
