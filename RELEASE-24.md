# Atlas AI Sprint 24 — Ask Atlas Memory

## Added
- Persistent Ask Atlas conversation history across dashboard navigation and browser refreshes.
- Current-topic indicator driven by Atlas conversation context rather than the latest raw question.
- Remembered exchange count so users can see that context is active.
- Conversation History viewer for reviewing recent questions and answers.
- New Chat control that clears both visible messages and conversational context.
- Improved follow-up continuity for short questions such as “Why?”, “What next?”, “Explain that,” and “Compare them.”
- Migration from the earlier Sprint 23 memory keys so existing conversations are not lost during upgrade.

## Preserved
- Sprint 23.0.1 navigation recovery.
- Executive Action Tracker.
- Dashboard, imports, transactions, history, billing, settings, and sign-out flows.
